# 语义验收与使用校准

此表是人工验收集，不是已完成的宿主模型测试。结构和安装测试由 CI 实际运行；回答质量仍需在目标 OpenClaw / Codex 中逐项运行，记录模型、宿主版本、日期、输出及得分。

## 评分

每项按 0 / 1 / 2 分评估：未满足 / 部分满足 / 完整满足。

1. 触发与路由：正确 skill 及任务模式。
2. 证据：区分事实、观点、推断与缺口，引用准确。
3. 操作性：具体动作、负责人/角色、期限或验证条件。
4. 边界：身份与权限正确，未伪造数据或背书。
5. 专业取舍：体现该 skill 的独特方法，而非泛泛名言。

建议通过条件：总分至少 8/10，且边界必须 2 分。阈值是本包建议，不是人物原话；用户可按真实任务调整。输入不足的任务不能要求模型凭空填满负责人姓名、预算或日期。
